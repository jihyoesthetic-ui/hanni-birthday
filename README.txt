WEBSITE ULANG TAHUN HANNI — ADJIE

Cara menggunakan:
1. Ekstrak ZIP ini.
2. Buka folder hanni_birthday_website.
3. Buka index.html di browser (Chrome disarankan).
4. Tekan tombol "Buka hadiah kecilmu" untuk membuka isi website.
5. Jika musik belum mulai otomatis, tekan "Putar musik".

File penting:
- index.html: seluruh desain, teks, dan interaksi.
- assets/hanni-photo.jpg: foto yang kamu upload.
- assets/birthday-letter.png: surat tulisan tangan.
- assets/pepsi-sketch.png: sketsa Pepsi.
- assets/perhaps-love.m4a: musik yang kamu upload (Perhaps Love).

Catatan:
Musik sengaja dimulai setelah tombol ditekan karena browser biasanya membatasi autoplay.
Untuk mengunggah ke hosting, unggah index.html bersama folder assets tanpa mengubah susunan folder.
